## Selected Build Profile

The selected model is a tagged source build for the staged player source
candidate. The same tag set is also the default Docker build argument in the
generated player candidate Dockerfile, so later local image builds from that
candidate compile the competition policy profile unless explicitly overridden
for review.

Canonical command:

```sh
make competition-runtime-build
```

Equivalent Go build profile:

```sh
GOTOOLCHAIN=local GOFLAGS=-mod=vendor GOTELEMETRY=off go build -tags "case_match_preview audit_detail_view entity_review_summary linked_case_export_detail network_room_detail" ./cmd/aml-api ./cmd/aml-worker ./scripts/migrate
```

`COMPETITION_TAGS` contains:

- `case_match_preview`;
- `audit_detail_view`;
- `entity_review_summary`;
- `linked_case_export_detail`;
- `network_room_detail`.

Legacy `aml*_vulnerable` tags remain organizer compatibility aliases only and
are not the canonical player-facing source build vocabulary.

## Guard Rails

- `scripts/check_competition_runtime_profile.py` fails if `COMPETITION_TAGS`
  omits any required policy tag or switches to legacy vulnerability labels.
- The same guard fails if `competition-runtime-build` does not compile with
  `-tags "$(COMPETITION_TAGS)"`.
- The staged player Dockerfile generated by `scripts/build_player_bundle.py`
  builds `aml-api`, `aml-worker`, and `aml-migrate` with
  `-tags "${COMPETITION_TAGS}"`.
- Generated Compose build sections pass the same `COMPETITION_TAGS` argument
  for migrate, API, and worker services.
- `competition-matrix-gate` runs the runtime-profile guard before the existing
  matrix validation.

## Anti-Goals

- Do not remove secure/default policy files from the organizer repository.
- Do not modify checker semantics, checker owner GET paths, checker flag

- Do not introduce debug/admin endpoints, direct DB shortcuts, public flag
  fields, or generic bypasses.
- Do not claim final player packaging is complete; this is a reproducible build
  profile and staged candidate path, not a final distribution artifact.
