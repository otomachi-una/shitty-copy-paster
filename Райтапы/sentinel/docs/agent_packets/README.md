# Agent Packets

Agent packets describe scoped work for implementation waves.

- Wave 01 prompt pool: `docs/agent_packets/wave_01_prompt_pool.md`
- Wave 01 fix prompt pool: `docs/agent_packets/wave_01_fix_prompt_pool.md`
- Future Wave 02 prompt pool: `docs/agent_packets/wave_02_prompt_pool.md`

Each task handoff must be written under `docs/wave_reports/` and include the required summary, implementation details, files changed, tests added, tests run, documentation updates, CTF/security invariant checks, self-review, risks/open questions, and orchestrator-review readiness.

Agent packets and wave reports are review artifacts. They do not replace the source-of-truth map, authoritative architecture documents, or ADRs for new decisions.
